Add a Tools menu to the PolicyEngine header, right after Research, with the same tools as policyengine.org's header. The US menu lists CliffWatch, the OBBBA household explorer and the state legislative tracker; the UK menu lists UK CliffWatch; other countries get no menu. Each menu ends with "All interactive tools". Every row is a full page load, because each tool runs as its own app on policyengine.org. New exports: `policyEngineFeaturedTools`, `getPolicyEngineFeaturedTools`, `getPolicyEngineAllToolsUrl` and the `NavItemChildConfig` type. `NavItemConfig` items and their dropdown rows take a new `external` flag that renders a plain link, bypassing `linkComponent` and `onNavigate`; rows inherit it from their item unless they set their own.
